# 歌词提取与导出

点击队列工具栏的「提取歌词」或左侧「歌词工作台」。选中一首时进入单曲校验，多选时进入批量导出。功能只写旁置歌词文件，不修改音频或其标签。

## 单曲校验

1. 输入或调整歌曲标题、艺术家，搜索 QQ 音乐与网易云音乐。
2. 选择具体版本，检查原文与译文；两个文本框均可编辑。
3. 核对实际导出预览、文件名和保存位置，再导出。

默认 SRT 格式，可改为 LRC 或 TXT。SRT 会转换时间轴、生成编号和开始／结束时间，不是修改后缀。没有时间标签的纯文本只能导出 TXT。来源无译文、纯音乐、服务错误等状态会直接提示。

## 批量选项

批量界面直接展示导出选项，并将调整保存为下次默认值：

- 格式：SRT、LRC、TXT。
- 内容：原文与译文、仅原文、仅译文。
- 双语组织：同条双行、同条单行、原译独立条目、原文／译文分文件。单行模式可调整分隔符。独立条目的 SRT 会在同一时段生成原文和译文两条字幕，部分播放器对重叠字幕的支持不同。
- 时间：整体偏移及译文额外偏移，单位毫秒；正数延后，负数提前。
- 文件名：原音频文件名、歌曲名 - 艺术家、艺术家 - 歌曲名，或自定义模板。支持 `{filename}`、`{title}`、`{artist}`、`{album}`、`{track}`、`{source}`，显示首曲命名示例。
- 来源：QQ 音乐、网易云音乐，默认均选中；同等匹配证据时优先 QQ。
- 位置：每首音频所在目录，或通过目录选择器指定统一位置。

分文件保存使用 `.original` 与 `.translation` 后缀，例如 `歌曲 - 艺术家.original.srt`。来源未提供译文时，仅保存原文并提示。同名文件自动加序号保留，不覆盖旧文件。分文件组写入中途失败或取消时，会清理本次已创建的部分文件。

批量仅自动处理标题、作者和版本等证据一致的歌曲。缺少关键信息、存在相近的不同作者候选或版本无法确认时，结果会标为待校验，可打开单曲对话框处理。取消会保留已完成结果，未处理歌曲不会继续发起请求。

## 时间与网络行为

保留歌词中的重复时间标签、整体偏移和空白结束标记。每条 SRT 默认在下一个时间点结束，最后一条使用已知歌曲时长；没有可靠时长时，使用最后时间点后 3 秒并给出提示。不为无时间信息的歌词编造同步时间。

搜索发送歌曲文本线索，不上传音频。提取仅使用所选的 QQ／网易云来源，不会静默替换成其他歌词平台；不需要账号或令牌。第三方接口可能限流、缺词或不可用，且歌词与译文可能来自不同发布版本，应核对后使用。
